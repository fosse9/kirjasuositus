# kirjasuositus
Sovelluksessa käyttäjät pystyvät jakamaan kirja suosituksia ja löytämään muiden käyttäjien suosittelemia kirjoja.

- Käyttäjä pystyy luomaan tunnuksen ja kirjautumaan sisään sovellukseen.
- Käyttäjä pystyy lisäämään kirja suosituksia sekä muokkaamaan ja poistamaan omia kirja suosituksiaan.
- Kirja suosituksessa näkyvät kirjan nimi, kirjailija ja käyttäjän kirjoittama kuvaus kirjasta.
- Käyttäjä näkee sovellukseen lisätyt kirja suositukset.
- Käyttäjä pystyy etsimään kirja suosituksia esimerkiksi kirjan nimen tai kirjailijan perusteella.
- Sovelluksessa on käyttäjäsivut, joilla näkyvät käyttäjän lisäämät kirjavinkit sekä tilastoja käyttäjän toiminnasta.
- Käyttäjä pystyy valitsemaan kirjavinkille luokitteluja, kuten:
 
     Genre: fantasia, scifi, historia, elämänkerta tai muu

     Kieli: suomi, englanti, ruotsi tai muu
- Käyttäjä pystyy kommentoimaan ja arvostelemaan omia ja muiden käyttäjien lisäämiä kirja suosituksia.
- Kirja suosituksen yhteydessä näytetään siihen liittyvät kommentit ja arvostelut.

Sovelluksen pääasiallinen tietokohde on kirja suositukset ja toissijainen tietokohde on kirja suositukseen liittyvä kommentti/arvostelu.
